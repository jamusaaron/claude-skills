# Methodology Frameworks

Expert knowledge bases for critical inquiry, source evaluation, and synthesis. Load during Phase 1 (planning) and Phase 5 (synthesis).

---

## CRAAP Test (Currency, Relevance, Authority, Accuracy, Purpose)

Quick screening filter before full 12-point evaluation.

| Criterion | Questions |
|-----------|-----------|
| **Currency** | When published? Updated? Links work? Still current for scope? |
| **Relevance** | Directly addresses research question? Appropriate level? |
| **Authority** | Author credentials? Publisher reputation? Contact info? |
| **Accuracy** | Evidence provided? Verifiable? Reviewed? Errors? |
| **Purpose** | Inform, teach, sell, entertain, persuade? Biases? |

**Decision:** Pass all 5 at adequate level → proceed to 12-point scoring. Fail 2+ → deprioritize unless uniquely valuable.

## Feynman Technique (Understanding Verification)

Use to test whether you truly understand a finding before synthesizing it.

1. **Choose a concept** — Select a key finding or mechanism from sources
2. **Teach it simply** — Explain in plain language as if to a non-expert
3. **Identify gaps** — Where does the explanation break down? What can't you explain?
4. **Return to source** — Fill gaps with targeted re-reading of primary sources
5. **Simplify further** — Use analogies; eliminate jargon

**Research application:** If you cannot explain a finding simply, you don't understand it well enough to cite with confidence. Flag for re-acquisition or downgrade confidence band.

## Lateral Reading (SIFT Method)

Don't vertically read a single source deeply before evaluating it. Read **across** sources to evaluate origin and credibility.

### S — Stop

Before engaging deeply, ask: Do I know this source? What is their reputation?

### I — Investigate the Source

- Search for the author/organization (not on their own site)
- Check Wikipedia, institutional pages, media bias charts (with caveats)
- Look for retractions, controversies, funding sources

### F — Find Better Coverage

- Search for the same claim across multiple outlets
- Prefer original reporting over aggregation
- Trace claims to primary data

### T — Trace Claims to Original Context

- Find the original study, report, or document
- Read the claim in full context (not cherry-picked quotes)
- Check if secondary sources accurately represent the primary

**When to use:** Every unfamiliar source during Phase 2-3. Especially critical for web sources, think tanks, and viral social media claims.

## Steelman Protocol

For contested claims, articulate the **strongest possible version** of each position before critique.

### Steps

1. **Identify the position** — State it in terms its strongest proponents would accept
2. **Find best evidence** — What is the strongest evidence supporters cite?
3. **Remove straw men** — Eliminate weak versions; engage with the best version
4. **Articulate steelman** — Present the strongest case fairly and completely
5. **Apply evidence** — Then evaluate with full credibility framework
6. **Indicate weight** — State relative evidential weight, not false equivalence

## Triangulation

Seek convergence across multiple methods, sources, and perspectives.

| Triangulation Type | Method |
|-------------------|--------|
| **Data triangulation** | Multiple datasets addressing same question |
| **Methodological triangulation** | Quantitative + qualitative + documentary evidence |
| **Investigator triangulation** | Multiple researchers/institutions reaching similar conclusions |
| **Theory triangulation** | Multiple theoretical frameworks converging |
| **Temporal triangulation** | Evidence consistent across time periods |

**Disconfirming triangulation:** Actively search for evidence that would falsify your emerging conclusion.

## Pre-Mortem Analysis

Assume the research produces misleading conclusions. Work backward to identify failure modes.

### Research Pre-Mortem (Phase 1)

"In 6 months, this research is shown to be wrong. What went wrong?"

Common answers:
- Relied on single source type (availability bias)
- Missed recent contradictory evidence (recency failure)
- Accepted secondary reporting without primary verification
- Scope drift away from original question
- Overconfidence in contested area

### Conclusion Pre-Mortem (Phase 5)

"Our top-line finding is later proven incorrect. What caused the error?"

Document mitigations and additional searches that would have caught it.

## Uncertainty Ladder

Assign confidence bands to every key finding.

| Band | Range | Criteria |
|------|-------|----------|
| **Very High** | >90% | Multiple convergent high-integrity sources; replicated or primary data |
| **High** | 70–90% | Strong evidence; minor gaps |
| **Medium** | 50–70% | Adequate evidence; notable uncertainties |
| **Low** | <50% | Limited, conflicting, or low-integrity evidence |

**Drivers to document:** Data volume, methodological consensus, external validation, verification loop results.

**Calibration rule:** When in doubt, downgrade one band. Overconfidence is a cardinal research sin.

## Bias Audit Checklist

Run before final output.

- [ ] Did I search for disconfirming evidence, not just supporting?
- [ ] Are source types diverse (not all news aggregating same press release)?
- [ ] Did early findings anchor subsequent searches?
- [ ] Are low-integrity sources clearly caveated?
- [ ] Did I steelman opposing views with evidential weight?
- [ ] Is confidence calibrated (not over-stated)?
- [ ] Did the query drift from the user's original intent?
- [ ] Are there geographic/temporal blind spots in source selection?

## Anti-Patterns Catalog

| Pattern | Symptom | Fix |
|---------|---------|-----|
| **Confirmation loop** | All sources agree; no disconfirming search | Add "criticism limitations controversy" queries |
| **Authority halo** | Famous name cited without evaluating specific claim | Evaluate each claim independently |
| **Recency trap** | Only latest sources; missing foundational context | Include historical queries when scope requires |
| **Citation laundering** | Blog cites blog cites study; original misrepresented | Trace to primary; read original |
| **False balance** | Equal weight to 95% consensus and 5% fringe | Weight by evidential quality, not presence |
| **Narrative fallacy** | Compelling story without data support | Privilege quantitative evidence |
| **Semantic drift** | Query evolved away from user intent | Revisit original query each phase |
| **Tool trust** | Search snippet treated as verified fact | Always browse/extract primary content |
