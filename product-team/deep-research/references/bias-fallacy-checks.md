# Bias, Fallacy, and Self-Audit Checks

Run this list against **your process**, not only against hostile sources. Confirmation bias in the researcher's query construction is the dominant failure mode.

## Researcher-side biases (highest leverage)

| Bias | How it shows up | Counter |
|------|-----------------|---------|
| Confirmation | Search strings that only match the expected answer | Mandatory disconfirming query; devil's advocate pass |
| Availability | First-page / first-tool results dominate | 4–8 variants; outlier search |
| Recency | Last-read paper wins | Vintage table; coverage_gap_analyzer |
| Selection | Convenient languages, open PDFs, English-only | Note language/paywall gaps explicitly |
| Anchoring | Phase 2 snippet becomes the thesis | Rewrite thesis from the matrix, not from memory |
| Shared-provenance illusion | 6 URLs, 1 dataset | citation_graph + triangulator |
| Semantic drift | Deliverable answers a cooler question | Re-read restated query |
| Overconfidence | Fluent synthesis, thin citations | Uncertainty ladder; never promote Low → High via prose |
| Sunk cost | "We already browsed 20 pages" | Early-stop rules are about *coverage*, not effort |
| False equivalence | Equal column inches to unequal evidence | Report weight, not symmetry |

## Source-side tricks

- **Denominator games:** "up to," survivors only, changing base.
- **Cherry timescale:** start the chart at the local minimum.
- **Surrogate endpoints:** commits as "productivity"; clicks as "demand."
- **P-hacking / forking paths:** many specs, one reported.
- **Reference laundering:** cite a blog that cites a tweet.
- **Credential theater:** impressive affiliations, off-topic doctorate.
- **Astroturf:** multiple "independent" comments, one comms shop.
- **Retraction invisibility:** PDF still ranks; check notices.

## Classic fallacies that infect research write-ups

- Post hoc / causal leap from timing
- Composition: true of a subgroup, asserted of the population
- Nirvana: rejecting a policy because it is not perfect
- Motte-and-bailey: defend a modest claim, sell a radical one
- Ad hominem as a substitute for methods critique (funding is a *lead*, not a refutation)
- Appeal to consensus without naming the consensus mechanism (survey? citation cartel? Cochrane?)

## Bias audit protocol (Phase 5)

Answer in writing (internal notes):

1. What did I search that could only confirm H1?
2. Which high-integrity contrary source did I actually read in full?
3. Which population is missing (geography, gender, informal sector, non-English)?
4. Did I treat social/viral material as testimony or as fact?
5. If my funder / user / prior belief were reversed, would Layer 1 change?

If (5) is "yes" and the evidence is the same, you are still framing. Fix the frame.

## Loaded-language scan

Flag in titles and executive summaries: shocking, destroyed, secret, always, never, proven, unprecedented (unless quantified), "the science is settled" (name the claim).

Prefer: magnitude, window, population, design, caveat.

## Calibration

Match language to bands:

- Very High / High: "The primary series shows…"
- Medium: "Evidence leans…, with important exceptions…"
- Low: "Insufficient to decide; here is the bound…"
